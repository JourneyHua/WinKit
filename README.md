# WinKit 系统管家

Windows 11 上的一站式轻量系统管家：**系统概览**、**右键菜单**、**此电脑显示项**、**资源管理器左侧导航栏**、**应用管理（卸载/更新/运行库/系统工具库，含 Scoop 包）**、**驱动管理（备份卸载与更新）**、**启动与服务（自启/服务/计划任务）**、**系统清理（缓存清理与大文件扫描）**、**系统调优与百宝箱（Win11 开关/端口诊断/深层面板直达）**、**文件占用解锁**、**文件与文件夹对比**、**重复文件检测**、**默认打开方式**、**事件日志诊断**、**Windows 更新管理**、**网络诊断**、**注册表体检**。
所有注册表与配置改动都先存快照，驱动卸载前自动导出驱动包备份，随时可撤销还原；不装后台服务。

仓库：https://github.com/JourneyHua/WinKit

## 能力边界（先读这段，避免预期落空）

| 你能做的 | 你做不到的（系统限制，不是 bug） |
|---|---|
| 一屏看清系统版本、CPU/内存/显卡、各卷占用、待重启、Defender/防火墙/安全启动状态 | 读取需要硬件驱动的实时传感器数据（温度、风扇转速）——那要内核驱动 |
| 屏蔽第三方软件塞进 Win11 一级菜单的项（两层深度屏蔽），或一键全局切回经典菜单 | 删掉一级菜单里的**内置项**（复制/粘贴/重命名/共享/发送到/删除/属性）——微软没有开放接口 |
| 禁用/删除/改名经典菜单里的任意项（8 个位置域） | 给右键菜单拖拽排序 |
| 隐藏此电脑里的用户文件夹、系统节点、任意盘符 | 改盘符字母 |
| 关闭软件钉在左侧导航栏的节点（iCloud Photos、WPS 云盘、应用宝等），彻底清理自动重建的顽固节点 | 把任意 exe 钉成导航栏一级图标（要写自定义 CLSID，非官方） |
| 增删快速访问固定项、调整顺序、开关导航窗格选项 | 给右键菜单拖拽排序 |
| 卸载传统桌面软件与商店/打包应用、清理卸载注册表残留、通过系统内置 `winget` 检查并一键更新软件 | 强制静默卸载没有提供静默参数的第三方安装器 |
| 按类别管理第三方驱动包（`oem*.inf`）、卸载前自动备份驱动包、通过 Windows Update 或本地 `.inf` 更新驱动 | 删除微软系统内置的核心基础驱动 |
| 对比两个文件夹/文件的差异（大小、时间、可选哈希），校验备份完整性 | 跨机器同步或三方合并（这是比对，不是同步工具） |
| 按内容查找重复文件并按组清理（进回收站） | 恢复回收站里被其它程序删掉的文件 |
| 查看每个扩展名当前关联到哪个程序、跳转系统设置更改、清理失效关联 | 绕过 `UserChoice` 哈希保护直接改默认程序（系统会判定篡改并重置） |
| 查出是哪个进程锁着某个文件并结束它（Restart Manager） | 结束受保护进程（系统关键进程、反作弊驱动保护的进程） |
| 汇总近 7/30 天的错误事件、定位蓝屏/崩溃/更新失败 | 解析蓝屏 dump 文件内容（需要调试器与符号） |
| 查看已装补丁、暂停/恢复更新、清理更新下载缓存 | 绕过企业组策略强制安装/屏蔽特定补丁 |
| 测网卡/DNS/网关、ICMP 延迟丢包、TCP 443 连通性、DNS 解析耗时、Wi-Fi 信号、系统代理 | 抓包分析（需要 pcap 驱动） |

针对更新版 Win11 对 PackagedCom 的保护，WinKit 采用「写入 `Shell Extensions\Blocked` + 将 `PackagedCom\Package\...\Class` 登记改名为 `.WinKitDisabled`」两层机制，并在状态列明确标注「已屏蔽·深度」。若包清单读不到（无法确认哪些 COM 类属于右键菜单），屏蔽按钮会被禁用，避免误伤预览器/后台任务等其它壳扩展。

## 运行要求

- Windows 11（已在 26H2 / build 26300 上验证）
- **.NET 10 Desktop Runtime**（框架依赖发布，约 2 MB 本体）
  → https://dotnet.microsoft.com/download/dotnet/10.0
- 运行时需要管理员权限（改 HKLM、屏蔽列表、此电脑节点都要写系统区）

## 快速开始

1. 双击 `dist\WinKit.exe`，接受 UAC 提权
2. 左侧选模块；每条改动都会即时生效，多数情况需要点顶部「重启资源管理器」才看得见效果
3. 改错了点顶部「撤销上一步」；想整体回到本次启动前，去「备份与还原」→「回滚本次会话」

## 各模块怎么用

- **全表头点击排序**：所有数据表格（右键菜单、应用管理、常用运行库、驱动管理、注册表体检、备份与还原、事件日志、网络诊断）均支持点击任意列头切换升序 `▲` / 降序 `▼` 排序；软件大小与快照大小按真实字节数排序，安装日期与快照时间按真实时间排序。
- **一键定位注册表 (`regedit`)**：在右键菜单、导航栏固定项、应用管理、注册表体检中，均支持右键菜单或快捷按钮一键打开系统 `regedit.exe` 并自动展开定位到对应注册表项。

### 系统概览（只读）

- 四张卡片：**系统**（版本/内部版本/计算机名/当前用户/安装日期/已运行时长）、**硬件**（CPU 型号与逻辑处理器数、内存总量与占用、显卡）、**存储**（每个卷的容量、已用百分比、可用空间）、**健康与安全**（待重启、Defender、防火墙、安全启动）。
- 全部走注册表、`Environment` 与 Win32（`GlobalMemoryStatusEx`），**不联网、不写任何东西**，打开即用。
- 占用超过 85% 标黄、95% 标红；待重启/防护关闭/安全启动未开启会标黄，方便一眼看出该处理什么。

### 文件占用解锁

- 删除或移动文件时提示“文件正在被使用”，在这里粘贴路径（或点「选择文件」）→「查询占用」，用系统自带的 **Restart Manager** 查出占用进程，显示 PID、类型（桌面程序/后台服务/资源管理器）、启动时间与程序路径。
- 支持单个「结束」或「结束全部占用进程」，结束前会二次确认；系统关键进程（PID 0/4）不可结束。
- 若运行环境连不上 Restart Manager 服务（受限会话/沙箱里会返回错误码 29），会自动退回到「已加载模块扫描」：至少能定位把该 DLL/EXE 装进进程的程序，并额外做一次独占打开测试，告诉你文件到底有没有被锁。

### 文件与文件夹对比

- 左右各选一个**文件夹**（递归或只看顶层），或选同类型的**两个文件**，点「开始对比」。
- 默认按「大小 + 最后写入时间」比较，几万个文件也很快；勾选「比对内容哈希」后，对参数完全相同的文件再算 SHA-256，能识别**大小和时间都相同但内容被改过**的情况。
- 结果按差异分类：内容不同、仅左侧、仅右侧、左侧较新、右侧较新；「只看差异」可过滤掉相同项。
- 每行可一键定位到左侧/右侧资源管理器并选中，或复制路径。
- 典型用途：校验备份是否完整、对比两份配置目录、确认「更新后的程序目录」到底动了哪些文件。

### 重复文件检测

- 先加扫描目录（「加入常用文件夹」可一键加入图片/视频/音乐/文档/下载），可设最小体积（支持 `500 KB` / `1 MB` / `2 GB` 这类写法），可选是否包含隐藏/系统文件。
- **三级校验**：按大小分组 → 头部 64KB 哈希 → 全文件 SHA-256。只有三级都相同的才算重复，同大小但内容不同不会被误判。
- 按「可节省空间」排序，每组显示份数、单份体积与可省空间；可「保留首份，其余移入回收站」，也可单独删除某一份。
- **清理一律进回收站**，不直接删除，随时可还原。
- 扫描在后台线程执行，可随时取消。

### 默认打开方式

- 列出本机所有扩展名（实测约 700 个）及其关联程序：扩展名、来源（用户指定 / 系统默认）、关联程序名、ProgID、打开命令。
- 支持按扩展名 / ProgID / 程序名搜索，可只看「用户指定」的项。
- **为什么不能直接改**：Windows 8 起 `UserChoice` 带哈希签名，直接写注册表会被系统判定篡改并自动重置，所以本工具不硬改关联，只做三件事：
  1. **更改**：跳到系统「默认应用」里该扩展名的设置页（官方支持的唯一可靠路径）；
  2. **打开方式**：调起系统的「打开方式」对话框，等价于资源管理器右键；
  3. **清理失效关联**：只处理「打开命令指向的 exe 已不存在」的扩展名，且只删 HKCU 下的默认值，带快照可撤销。

### 事件日志诊断

- 拉取 `System` 与 `Application` 两个日志里近 **7 天 / 30 天** 的「错误 + 严重」事件，按 **来源 + 事件 ID + 级别** 归并成一行，显示出现次数、首次/最后时间与示例数据。
- 自动分类：蓝屏/意外关机、应用崩溃、更新失败、磁盘/存储、电源/启动、网络、安全、服务启动失败、证书/加密、COM 组件、性能计数器。
- 支持复制单条详情、一键打开系统「事件查看器」。
- 实现上调用系统自带 `wevtutil qe ... /f:xml`，不引入 EventLog NuGet 包，普通用户即可读取（Security 日志除外）。

### Windows 更新

- **已安装补丁**：优先读 CBS 包仓库（`Component Based Servicing\Packages`，Win11 的补丁登记在这里），再兜底读 `Uninstall` 登记项；显示 KB 编号、类别、安装时间。全程本地读取，不联网。
- **暂停 / 恢复更新**：写 USO 的 `PauseUpdatesStartTime` / `PauseUpdatesExpiryTime`，提供 7 / 14 / 35 天三档，改前自动快照，随时可撤销。
- **清理更新下载缓存**：临时停止 `wuauserv` → 清空 `C:\Windows\SoftwareDistribution\Download` → 重新启动服务，报告删除文件数与释放空间。
- 顶部状态行显示暂停状态、服务启动类型、缓存体积、是否待重启；检测到组策略配置时会提示「部分开关可能被策略接管」。

### 网络诊断

- **网卡与 DNS**：列出有地址或网关的网卡（自动过滤 QoS/WFP 等过滤驱动伪接口），显示类型、状态、IPv4、网关、DNS。
- **延迟与丢包（ICMP）**：对网关、223.5.5.5、8.8.8.8 各发 4 个包，显示平均/最小/最大延迟与丢包数。
- **外网连通（TCP 443）**：对百度/微软/GitHub 做 TCP 连接测试——ICMP 常被防火墙或代理拦掉，TCP 结果更可靠。
- **DNS 解析耗时**：解析 3 个常见域名并计时，超过 500 ms 标黄。
- **Wi-Fi 与系统代理**：解析 `netsh wlan show interfaces`（SSID/状态/信号/协议/信道/速率，需要管理员权限）与 `Internet Settings` 里的代理开关、服务器、PAC 地址、例外。
- 快捷操作：刷新 DNS 缓存、重置 Winsock、重置 TCP/IP、打开网络设置、打开 hosts 文件。

### 右键菜单

- **全局切换「默认直接展开经典菜单」**：顶栏右侧提供一键开关（控制 `HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32`），开启并重启资源管理器后，右键直接弹出完整经典菜单，无需再点「显示更多选项」；同样支持快照撤销。
- **一级菜单（右键直接看到的那层）**：不点「显示更多选项」时弹出的紧凑菜单。
  - **数据源是包清单**（`AppxManifest.xml` 里的 `windows.fileExplorerContextMenus`），不是注册表里的 COM 类清单。后者只说明"这个包注册了哪些 COM 类"，会把背景任务、预览器全混进来——这正是之前"显示中却看不到"的原因。
  - 清单里 `<ItemType Type="*">` / `Directory` / `Directory\Background` / `Drive` 就是作用域，左侧域树据此分组。
  - **驱动器会继承「文件夹」作用域的项**：VS Code、PowerRename 只声明了 `Directory`，却照样出现在驱动器右键里。所以驱动器分组 = 声明 `Drive` 的 + 被继承的文件夹项，后者在「继承」列标注。
  - 读不到清单的包单独归入「作用域未确认」并置灰，不假装它一定在菜单里。
  - **两层屏蔽**：勾掉或点「屏蔽」= ① 把该软件所有 `IExplorerCommand` 的 CLSID 写进 `Shell Extensions\Blocked`；② 遍历该软件合并的全部版本包，将 `PackagedCom\Package\...\Class\{CLSID}` 改名为 `.WinKitDisabled`（状态列显示「已屏蔽·深度」）。
  - 行内「卸载」= 调它自己的卸载程序（WinKit 不删任何文件），卸载后每 3 秒轮询、最多 10 分钟，自动复查残留并报告；也可随时点顶栏「复查残留」或「重新扫描」手动复查。
  - 内置项（打开、复制、粘贴、重命名、共享、发送到、属性、显示更多选项）由 Windows 硬编码，无可移除接口。
- **经典菜单（显示更多选项）**：8 个位置域——文件、文件夹、文件夹空白处、驱动器、桌面空白处、库、发送到、新建。
  - 勾选框 = 启用/禁用（`LegacyDisable` 或屏蔽列表，完全可逆）
  - 「改名」= 写 `MUIVerb`，只改显示名
  - 「复制路径」或表格行右键菜单 = 一键复制注册表路径或命令路径
  - 「删除」= 真删注册表项或发送到快捷方式，但删前自动快照，可撤销
  - 默认视图是「仅第三方 + 高频四域」，因为你的机器上有 2000+ 条，全平铺没法用
- **发送到**：本质是快捷方式文件，禁用 = 移到 `%APPDATA%\WinKit\SendToBackup`；启用、禁用、删除均包含轻量文件快照，可通过「撤销上一步」或「备份与还原」恢复。
- **新建**：禁用 = 把 `ShellNew` 键改名，数据保留

### 此电脑

- **用户文件夹**：3D 对象、桌面、下载、文档、图片、音乐、视频（ThisPCPolicy）
- **系统节点**：控制面板、网络、第三方注册的命名空间（WPS 云盘、腾讯应用宝等）。
  - 带 `HiddenByDefault` 的系统节点：隐藏 = 把该值置 1（**不删键**），恢复 = 置 0，零损失。
  - 第三方节点没有该值：隐藏 = 删键，删前会把整键内容备份到 `%LOCALAPPDATA%\WinKit\NodeBackups`；恢复时用这份快照原样写回，**保留原默认值（`CLSID_xxx` 名称引用）与 `HiddenByDefault`**，不会重建成裸 GUID。
  - 被 WinKit 隐藏过的节点会继续列在列表里（标记「已被 WinKit 隐藏」），随时可以勾回来。
- **驱动器**：隐藏 = 写 `NoDrives` 位掩码。只影响资源管理器显示，不动盘符和数据

### 导航栏

- **导航栏固定项（软件节点）**：iCloud Photos、WPS 云盘、腾讯应用宝文件管理、小米云盘、OneDrive 这类软件自己钉在"此电脑"下面的节点。
  原理是 CLSID 上的 `System.IsPinnedToNameSpaceTree`，关掉 = 把它改成 0，**不删注册表项、不卸载软件**，勾回来即恢复。改完需要重启资源管理器看效果。
- **顽固节点（会自动重建）**：有些软件（典型是 WPS 云盘）每次启动都换一个新 GUID 重新钉上去，所以按单个 ID 关永远关不完。
  这里按显示名把同族 GUID 归组，一次性删掉全部注册项（此电脑 + 导航栏），并能定位/结束重建它的后台进程（如 `wpscloudsvr.exe`）。
  注意：结束进程只影响该软件的后台组件，别去结束你自己正在用的主程序。
- **快速访问固定项**：可增（选文件夹）、删（取消固定）、调顺序（「应用新顺序」会先全部取消再按列表重钉，过程几秒）
  - 顺序重建在后台线程执行，界面不会假死；若有项目未能恢复固定，会弹出清单告诉你具体哪几个需要手动重钉，而不是默默当作成功。
- 「最近使用」的条目只能读，取消固定请用资源管理器右键
- 四个导航窗格开关直接写 `Explorer\Advanced`

### 应用管理（卸载、更新与常用运行库体检）

- **全量应用列表**：汇总本机已安装的**传统桌面软件**（注册表 `Uninstall`）、**Microsoft Store / MSIX 打包应用**与 **Scoop 包**，支持按「全部 / 桌面软件 / 商店与打包 / Scoop 包 / 仅看可更新」筛选与关键词搜索，展示版本、类型、体积、安装日期与安装位置。
- **Scoop 包集成**：直接读本地目录，**离线**即可判断可升级版本——已装版本来自 `apps\<name>\current\`（`scoop-manifest.json` 与旧版 `manifest.json` 两种文件名都支持），可升级版本来自 `buckets\<bucket>\bucket\<name>.json`。只有真正执行「更新 / 卸载」时才调用 `scoop` 命令。读不到版本（如 `scoop` 自身是自举安装）会如实标注「版本未知」，不虚报可升级。
- **软件卸载与残留清理**：
  - 传统桌面软件调起官方自带卸载程序并自动监测卸载完成；商店与打包应用通过系统接口直接卸载。
  - 卸载完成后自动扫描**失效的卸载注册项与残留 COM 类（CLSID）**，支持一键通过快照清理（可随时撤销）；若原安装目录仍有残留文件，提供一键打开定位，不擅自删用户个人数据。
- **软件更新（基于 `winget` 与 `scoop`）**：
  - 点「检查更新」同时比对两类来源：`winget`（调用 Windows 11 内置包管理器）与 `scoop`（读本地 bucket 清单，离线）。列表中直观显示 `当前版本 → 最新版本`。
  - 支持单软件「更新」与顶栏「一键更新全部」，winget 默认后台静默升级并在状态栏实时显示进度（需要交互的安装器自动切换为交互模式）；Scoop 包走 `scoop update <name>`。
- **常用运行库体检与安装**：
  - 顶部一键切换「常用运行库体检与安装」子视图，本地毫秒级检测四大类共 21 项核心运行库：
    - **Visual C++ 运行库**：VC++ 2005 / 2008 / 2010 / 2012 / 2013 / 2015–2022（x86 与 x64 独立检测）
    - **.NET 运行时**：.NET Framework 3.5 (2.0/3.0)、.NET Framework 4.8+、.NET Desktop Runtime 6 / 8 / 9 / 10 (x64)
    - **游戏与多媒体组件**：DirectX 9.0c (June 2010 Runtime)、Microsoft XNA Framework 4.0、OpenAL 音频库
    - **现代桌面组件**：Microsoft Edge WebView2 Runtime、Windows App Runtime (WinUI 3)
  - 缺失项红色高亮标注，支持单项「安装 / 修复」或顶栏「一键补齐缺失运行库」，全部调用系统内置 `winget` 或 `DISM` 官方源安装。
- **常用系统工具库**：
  - 精选五大类共 22 款纯净无广告高口碑系统增强与装机必备工具：
    - **微软官方增强**：PowerToys、Sysinternals Suite、Autoruns、Process Explorer、微软电脑管家
    - **文件与空间工具**：Everything、WizTree、7-Zip、NanaZip
    - **卸载与系统维护**：Bulk Crap Uninstaller、Geek Uninstaller、Rufus、Ventoy
    - **硬件监控与检测**：CPU-Z、GPU-Z、CrystalDiskInfo、HWiNFO、TrafficMonitor
    - **开发与终端增强**：Windows Terminal、Git、Visual Studio Code、Notepad3
  - 自动检测本机安装状态、版本与路径；已安装工具支持直接「启动」与打开目录，未安装工具支持勾选后通过 `winget` 官方源一键批量装机。

### 驱动管理（备份卸载与双通道更新）

- **第三方驱动包枚举**：调用 `pnputil /enum-drivers` 枚举本机所有第三方驱动包（`oem*.inf`），左侧按设备类别分组，顶部支持按「全部级别 / 核心驱动 / 普通外设」筛选，展示原始 `.inf`、厂商、版本与日期、数字签名者及风险级别，并提供一键打开系统「设备管理器 (`devmgmt.msc`)」。
- **先备份、后卸载**：
  - 点击「卸载」前，自动调用 `pnputil /export-driver` 将该驱动包完整导出备份至 `%LOCALAPPDATA%\WinKit\DriverBackups`。
  - 对显卡、网卡、存储控制器、主板芯片组等核心驱动弹出高亮风险警告，确认后执行 `pnputil /delete-driver /uninstall`。
  - 顶部提供「从备份还原」按钮，随时可将历史备份的驱动包一键重装恢复。
- **双通道驱动更新**：
  - **官方在线更新**：通过系统内置 Windows Update 接口（`Microsoft.Update.Session` 定向检索 `Type='Driver'`）扫描微软官方 WHQL 驱动更新，支持在界面内直接下载并安装。
  - **本地驱动安装**：支持选择本地 `.inf` 驱动包一键安装或升级，并提供「扫描硬件」快捷触发。

### 启动与服务（自启、后台服务与计划任务）

- **开机启动项**：汇总当前用户与系统全局 `Run` / `RunOnce`（含 `WOW6432Node`）及开始菜单「启动」文件夹，接入 Windows 原生 `StartupApproved` 机制实现**无损启用/禁用切换**（改前自动记录注册表快照），并支持打开目录、定位注册表与删除失效项。
- **后台服务**：枚举 Win32 服务（默认过滤微软系统核心服务，支持切换查看全部），展示运行状态与启动类型，支持一键「启动 / 停止」及修改自启类型（自动 / 手动 / 禁用，修改前自动保存注册表快照）。
- **计划任务**：枚举非微软系统内置的第三方定时计划任务，支持一键「启用 / 禁用」与「立即运行」。

### 系统清理（垃圾缓存清理与大文件扫描）

- **垃圾与缓存清理**：默认勾选 100% 安全的系统临时文件 (`%TEMP%`、`C:\Windows\Temp`)、Windows Update 下载缓存、程序崩溃转储 (`CrashDumps` / `Minidump` / `WER`)、显卡着色器缓存、CBS 日志与缩略图缓存；并提供回收站清空、最近文档快捷方式与开发包缓存（NuGet / npm / pip）等可选清理项，支持一键调用 `DISM /StartComponentCleanup` 清理 WinSxS 旧组件存储。
- **大文件扫描**：支持按用户目录或任意磁盘分区秒扫 `> 100 MB` 的大文件，按真实字节数排序，支持定位文件、复制路径与安全移入系统回收站。

### 系统调优与百宝箱

- **Win11 系统调优开关**：汇总 15 项高频资源管理器体验、任务栏/桌面与系统隐私去广告开关（显示扩展名、显示隐藏文件、打开默认进「此电脑」、任务栏靠左对齐、隐藏搜索/小组件/任务视图、桌面显示「此电脑/控制面板」、关闭开始菜单与锁屏推广广告、禁用广告追踪 ID 等），全部基于注册表快照可逆修改。
- **网络与端口占用诊断**：实时解析 `netstat -ano` 端口占用表并关联进程名与程序路径，支持按端口号/进程搜索、一键结束占用端口的进程；顶栏提供「刷新 DNS」、「重置 Winsock」、「重置 TCP/IP 协议栈」与「编辑 Hosts 文件」。
- **系统深层面板直达**：汇总 16 项经典深层管理工具（服务、任务计划、组策略、注册表、磁盘管理、设备管理器、环境变量、可选功能、网卡适配器、电源计划、程序和功能、证书管理、资源监视器、性能监视器、可靠性监视器、DirectX 诊断）一键调起。

### 注册表管理

按分类定向扫描，不做全表遍历（单类 3000 条上限，超限会标注结果可能不完整）：

| 分类 | 内容 | 可清理 |
|---|---|---|
| 启动项 | Run / RunOnce / Winlogon | 指向的文件不存在时 |
| 右键菜单 | 各域条目汇总，管理请到右键菜单页 | 否 |
| 文件关联 | `.ext → ProgID → 打开命令` | 否（只报告） |
| 卸载信息 | 卸载程序已失效的记录 | 是 |
| 失效残留 | CLSID 的 InprocServer32 指向的 DLL 不存在 | 是 |
| 策略与限制 | Policies 树，只展示 | 否 |
| 环境变量 / PATH | PATH 里已不存在的目录 | 是（只从 PATH 移除该条） |

**只有「可证明无效」的项才有清理按钮**——证据就是它指向的文件或目录确实不存在。支持逐条清理，也支持点顶栏「清理全部可疑项」对当前筛选列表一键批量清理（整批合并保存为 1 份快照，点一次「撤销上一步」即可整批恢复）。其余一律只读，避免把还能用的配置删掉。

## 安全机制

- 每次写入前，把**受影响的注册表键**（含子键、值、类型）及**发送到快捷方式文件**存成 JSON 快照：`%LOCALAPPDATA%\WinKit\Backups`
- 只存改动涉及的部分，几十 KB 一份，保留最近 50 份
- 「撤销上一步」逐条精确还原并自动清理已撤销的备份文件；「回滚本次会话」按相反顺序全撤
- 还原是**差量写回**：先删掉快照里没有的值/子键，再写回快照中的值，不会整树删除重建，键的安全描述符保持不动
- **快照不完整时拒绝破坏性还原**：子键数超过上限（20000）会标记 `Truncated`，还原直接报错，而不是删掉没记下来的子树
- **读取被拒的键标记 `CaptureFailed`**：不会把「没权限读」误判成「原本不存在」，撤销时不会去删一个真实存在的键
- 快照里的注册表根只接受 `HKCU` / `HKLM`，手改或损坏的备份文件会被拒绝，不会落到系统区
- 写操作抛异常时**自动回滚**；撤销/回滚有失败项时如实列出失败清单，不用「已撤销」掩盖
- 除「网络诊断」会主动发包（ICMP / TCP 443 / DNS 解析）外，其余模块全程无网络请求

## 开发

SDK 装在用户目录（避免 UAC）：`%USERPROFILE%\dotnet-sdk\dotnet.exe`，或直接用你机器上任意 `dotnet`（.NET 10 SDK）。

```bash
# 编译
dotnet build WinKit.slnx

# 发布（框架依赖）
dotnet publish src/WinKit/WinKit.csproj -c Release -o dist

# 发布（自包含单目录，免装运行时，约 160 MB）
dotnet publish src/WinKit/WinKit.csproj -c Release -r win-x64 --self-contained true -o dist-standalone

# 界面离屏自检：逐模块渲染 PNG，不弹窗口
dist\WinKit.exe --smoke C:\temp\smoke

# 只读探测：枚举全部菜单项/节点/驱动器/快速访问，落一份报告
dotnet run --project tools/Probe -- report.txt

# 自测：快照/撤销/还原保真 + 解析器与分类器（约 45 项）
dotnet run --project tools/Probe -- --selftest
```

自测会在低完整性级别（受限令牌/沙箱）下自动跳过写入类用例并标注 `SKIP`，只读用例照常执行；
要覆盖快照写入与撤销，请在正常桌面会话（中完整性以上）运行。

免提权调试界面：加 `-p:ApplicationManifest=app.preview.manifest` 编译（`app.preview.manifest` 把 `requireAdministrator` 换成 `asInvoker`）。
注意：只改属性不会让已生成的 apphost 重新嵌入清单，必须加 `-t:Rebuild`，否则 exe 仍然要求提权：

```bash
dotnet build src/WinKit/WinKit.csproj -c Release -t:Rebuild -p:ApplicationManifest=app.preview.manifest
```

## 已知限制

1. 一级菜单的 PackagedCom 项采用 `Shell Extensions\Blocked` + `PackagedCom\Package\...\Class` 改名两层屏蔽；若应用更新版本，Windows 会重新注册新版本的包，届时重新屏蔽一次即可
2. 快速访问排序靠「全部取消后重钉」，期间列表会短暂清空
3. `NoDrives` 是策略键，个别系统需要注销才完全生效
4. 驱动器隐藏只作用于当前用户
5. 文件占用解锁依赖 Restart Manager 服务；在受限会话/沙箱里会退回到「已加载模块扫描」，只能定位 DLL/EXE 类占用
6. Wi-Fi 详情（`netsh wlan show interfaces`）需要管理员权限，未提权时只显示提示
7. 事件日志只读 `System` / `Application`，`Security` 日志需要额外权限，未纳入
8. 网络诊断会主动发包（ICMP / TCP 443 / DNS 解析），这是唯一会联网的模块；其余模块全程无网络请求
